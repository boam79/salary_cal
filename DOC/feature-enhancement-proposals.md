# 기능 고도화 제안서 (금융 계산기)

## 목적

본 문서는 “금융 계산기” 서비스의 **기능 고도화 아이디어**를 제품 관점(사용자 가치)에서 정리하고, 구현 시 **작업 단위/리스크/우선순위**까지 포함해 바로 개발 티켓으로 쪼갤 수 있게 하는 것을 목표로 합니다.

---

## 우선순위 기준(권장)

- **P0**: 사용자에게 “바로 돈/시간”을 절약시키고 재방문을 유도하는 기능
- **P1**: 결과 신뢰도/설명력/비교 기능(“이 계산이 맞나?”를 해소)
- **P2**: 공유/저장/자동 업데이트/개인화(확장성)

---

## P0 제안 (가치 대비 구현 효율이 큰 것)

### 1) 결과 “저장/불러오기”(최근 5개) + URL 공유

- **사용자 가치**: 같은 입력을 반복하지 않음. 가족/지인과 결과 공유 가능.
- **핵심 기능**:
  - 계산 완료 시 입력값을 `localStorage`에 저장(계산기별 최근 5개)
  - “링크로 공유” 버튼 → `?calc=salary&annual=5000` 같은 쿼리로 복원
- **구현 단위**:
  - 공통 `serialize/deserialize` 유틸
  - 각 계산기별 입력 필드 매핑 테이블
  - `navigationManager`에서 쿼리 파싱 후 화면+입력 복원
- **리스크**: URL 길이/개인정보(민감값) 포함 가능성 → “민감값 없음” 안내/옵션.

### 2) “비교 모드”: A안 vs B안

- **사용자 가치**: 연봉 인상 전/후, 금리 변경 전/후, 대출 기간 변경 전/후를 한 화면에서 비교.
- **적용 대상**: 연봉/월급, 대출, 적금/예금, DSR(우선)
- **UI**:
  - 좌/우 카드(입력 2세트) + 결과 차이(Δ) 강조
- **리스크**: 화면 복잡도 증가 → 모바일에선 탭/스와이프 형태 권장.

### 3) “근거/설명” 강화: 계산 과정 자동 요약 + 복사

- **사용자 가치**: 신뢰도 상승, 문의 감소, 공유 용이.
- **기능**:
  - 결과 요약 텍스트(예: “연봉 5,000만원 기준…”)
  - “요약 복사” 버튼(클립보드)

---

## P1 제안 (신뢰도/정확성/도메인 확장)

### 4) 연봉 계산 고도화: 부양가족/비과세/기타 공제 옵션

- **사용자 가치**: 실제 실수령액과의 차이를 줄임.
- **옵션 예시**:
  - 부양가족 수, 비과세(식대 등), 연말정산 주요 공제 항목 체크
- **리스크**:
  - 세법이 복잡해짐 → “간편/상세” 모드 분리(기본은 간편).

### 5) 퇴직금: 평균임금 자동 산정 보조 + 중간정산/상여 반영 옵션

- **사용자 가치**: 현실 케이스 반영률 상승.
- **리스크**: 입력 UI 복잡 → “추가 옵션 펼치기” 형태 권장.

### 6) 부동산: 중개수수료/보유세/양도세 “지역/주택 수” 옵션 확장

- **사용자 가치**: 실제 규정 반영.
- **리스크**: 규정 업데이트 부담 → 규칙/버전 표기 강화 필요.

---

## P2 제안 (개인화/자동화/운영)

### 7) “내 계산기” 즐겨찾기 + 홈 커스터마이즈

- **사용자 가치**: 자주 쓰는 계산기 접근성 향상.
- **구현**: 즐겨찾기 목록 localStorage 저장, 홈 상단에 노출.

### 8) 알림/캘린더 연동(옵션)

- **예시**: 적금 만기일, 대출 이자 변경 시점, 연말정산 시즌 알림.
- **리스크**: 알림 권한/스팸 인식 → opt-in 필수.

### 9) 백엔드(로또/뉴스) 관측 강화

- **기능**: 간단한 대시보드(최근 sync 시각, 데이터 개수, 오류 카운트)
- **목표**: 운영 비용 감소 및 장애 대응 속도 개선.

---

## 추천 로드맵(기능 고도화)

1. **저장/URL 공유** (P0) → 재방문/공유 유도
2. **비교 모드** (P0) → 사용시간 증가
3. **설명/요약 복사** (P0/P1) → 신뢰도 강화
4. 연봉/대출 상세 옵션(“상세 모드”) (P1)

---

## 실행 계획 템플릿 (티켓화 기준)

각 제안은 아래 템플릿으로 이슈/작업으로 분해하는 것을 권장합니다.

- **MVP 범위**: 이번 배포에서 꼭 필요한 최소 기능
- **비-MVP(후속)**: 다음 배포로 미뤄도 되는 기능
- **수용 기준(AC)**: QA가 체크할 명확한 완료 조건
- **지표(KPI)**: 배포 후 개선 여부를 판단할 수치
- **의존성**: 선행 작업/공용 모듈/배포 조건

---

## 제안별 실행 상세 (MVP/AC/KPI)

### 1) 결과 저장/불러오기 + URL 공유

- **MVP**
  - 계산기별 최근 5개 입력값 저장/복원
  - `copy link` 버튼으로 URL 복사
  - 페이지 재진입 시 최근 1개 자동 복원(옵션)
- **비-MVP**
  - 기기 간 동기화(로그인 기반)
  - 공유 링크 만료/암호화
- **수용 기준(AC)**
  - 저장 후 새로고침해도 동일 입력값 복원
  - 공유 URL 접속 시 동일 계산기 화면+입력값 복원
  - 민감 필드(있다면) URL 포함 여부를 사용자에게 명시
- **KPI**
  - 재방문 세션 비율
  - “계산 완료 후 공유 버튼 클릭률”
- **의존성**
  - 입력 필드 매핑 테이블 표준화
  - `navigationManager` 쿼리 파싱 안정화

### 2) 비교 모드 (A/B)

- **MVP**
  - 연봉/대출 계산기에 한해 A/B 비교 제공
  - 차이값(월 실수령액 차이, 총이자 차이) 강조
- **비-MVP**
  - 모든 계산기로 확장
  - 비교 결과 이미지 내보내기
- **수용 기준(AC)**
  - A/B 입력 전환 시 결과가 서로 독립적으로 유지
  - 모바일 화면에서 비교 UI가 깨지지 않음
- **KPI**
  - 비교 모드 사용률
  - 비교 모드 사용 세션의 체류시간 증가율
- **의존성**
  - 공통 결과 카드 컴포넌트화
  - 계산 엔진 순수 함수 재사용

### 3) 계산 근거 자동 요약 + 복사

- **MVP**
  - 결과 요약 문장 자동 생성
  - 클립보드 복사 버튼
- **비-MVP**
  - PDF/이미지 내보내기
  - 카카오톡 공유 포맷 최적화
- **수용 기준(AC)**
  - 주요 계산기(연봉/세금/대출)에서 요약 문장이 생성됨
  - 복사 버튼 클릭 시 사용자 피드백(토스트) 표시
- **KPI**
  - 요약 복사 클릭률
  - 문의 시 “결과 근거 부족” 관련 피드백 감소
- **의존성**
  - 계산 결과 객체 표준화(요약 생성용)

### 4) 연봉 계산 상세 옵션

- **MVP**
  - 간편/상세 모드 분리
  - 상세 모드에 부양가족/비과세 항목 1~2개 추가
- **비-MVP**
  - 연말정산 항목 전체 반영
- **수용 기준(AC)**
  - 간편 모드 UX 변경 없음(입력 최소 유지)
  - 상세 모드 옵션 반영 시 결과값이 일관되게 변함
- **KPI**
  - 상세 모드 사용률
  - 상세 모드 이탈률(너무 복잡한지 판단)
- **의존성**
  - 세율/공제 설정 테이블 확장
  - 회귀 테스트 케이스 추가

---

## 리스크 관리 체크리스트

- 규정 변경 기능은 모두 **기준일/버전 표시**를 UI에 노출한다.
- 계산식 변경 PR은 반드시
  - 단위 테스트(Vitest)
  - 핵심 E2E 스모크(Playwright)
  를 동시에 통과해야 머지한다.
- “간편 모드” 입력 복잡도는 늘리지 않는다(고도화는 상세 모드에 격리).

---

## 추가 메모(실행 전 체크)

- 기능 확장 시에도 “간편 모드”는 **입력 최소/즉시 결과**를 유지하는 것이 핵심입니다.
- 세법/요율 변경이 있는 기능은 반드시 **버전/기준일 표시**를 유지하세요.
