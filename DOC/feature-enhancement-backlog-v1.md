# 기능 고도화 1차 백로그 (실행용)

## 문서 목적

본 문서는 `feature-enhancement-proposals.md`를 기반으로, 실제 구현 가능한 작업 단위로 쪼갠 **1차 실행 백로그**입니다.

- 우선순위: P0 먼저, 이후 P1
- 각 항목은 “작업 단위 + 완료 조건(AC) + 테스트”를 포함
- 비개발자도 진행 상황을 확인할 수 있도록 체크리스트 중심

---

## Sprint 1 (P0) - 사용자 체감 가치 우선

### FEAT-001: 결과 저장/불러오기 (최근 5개)

- **범위(MVP)**
  - 계산기별 최근 입력 5개 localStorage 저장
  - 저장 목록에서 클릭 시 입력값 복원
- **작업 단위**
  - [ ] `js/core/storage.js` 유틸 추가 (`saveRecent`, `getRecent`, `clearRecent`)
  - [ ] 계산기별 입력 필드 매핑 테이블 정의
  - [ ] 계산 완료 시 저장 트리거 연결(연봉/세금/대출 우선)
  - [ ] 최근 기록 UI(목록/선택/삭제) 추가
- **수용 기준(AC)**
  - [ ] 동일 브라우저에서 새로고침 후 최근 기록 복원 가능
  - [ ] 계산기별로 기록이 분리됨
  - [ ] 기록 5개 초과 시 오래된 항목 삭제됨
- **테스트**
  - [ ] Vitest: 저장/복원/최대개수 처리
  - [ ] E2E: 저장 후 새로고침 복원

### FEAT-002: URL 공유 (딥링크 복원)

- **범위(MVP)**
  - 현재 계산기 상태를 URL query로 인코딩
  - URL 접속 시 화면/입력값 자동 복원
- **작업 단위**
  - [ ] `serializeCalculatorState()` / `deserializeCalculatorState()` 유틸
  - [ ] `navigationManager` 초기화 시 query 파싱 복원
  - [ ] “링크 복사” 버튼 및 복사 성공 피드백 추가
- **수용 기준(AC)**
  - [ ] 복사한 URL을 새 탭에서 열면 동일 계산기와 입력값이 복원됨
  - [ ] 잘못된 query 값은 앱이 깨지지 않고 무시됨
- **테스트**
  - [ ] Vitest: serialize/deserialize round-trip
  - [ ] E2E: URL 진입 복원 시나리오

### FEAT-003: 계산 결과 요약문 + 복사

- **범위(MVP)**
  - 연봉/세금/대출 결과를 1~2문장으로 요약
  - 요약문 복사 버튼 제공
- **작업 단위**
  - [ ] 계산기별 요약 생성기(`js/domain/summary/*.js`)
  - [ ] 결과 영역에 요약 카드 추가
  - [ ] 클립보드 API 실패 시 fallback 처리
- **수용 기준(AC)**
  - [ ] 결과 계산 후 요약문이 항상 생성됨(빈값/NaN 없음)
  - [ ] 복사 버튼 클릭 시 사용자 피드백 표시
- **테스트**
  - [ ] Vitest: 요약문 문자열 생성 규칙
  - [ ] E2E: 복사 버튼 클릭 플로우

## Sprint 2 (P0/P1) - 비교/설명 강화

### FEAT-004: 비교 모드 A/B (연봉/대출 우선)

- **범위(MVP)**
  - 동일 계산기에서 입력 A/B 두 세트를 비교
  - 차이값(Delta) 강조
- **작업 단위**
  - [ ] 비교 상태 모델 추가(`left`, `right`)
  - [ ] 비교 결과 카드 UI 추가
  - [ ] 모바일 레이아웃 대응(탭 전환 또는 세로 스택)
- **수용 기준(AC)**
  - [ ] A/B 각각의 입력/결과가 독립 유지
  - [ ] 차이값 계산(+, -)이 정확
- **테스트**
  - [ ] Vitest: delta 계산
  - [ ] E2E: A/B 입력 및 결과 비교

### FEAT-005: 설명/근거 보기 UX 고도화

- **범위(MVP)**
  - 계산 단계별 설명을 템플릿화해 일관성 확보
  - “근거 기준일/버전”을 결과 영역에 표시
- **수용 기준(AC)**
  - [ ] 연봉/세금/대출에 기준일/버전 표시
  - [ ] 설명 토글 시 레이아웃 깨짐 없음

## Sprint 3 (P1) - 도메인 정확성 확장

### FEAT-006: 연봉 상세 모드 (간편/상세 분리)

- **범위(MVP)**
  - 간편 모드 유지 + 상세 모드에 부양가족/비과세 항목 일부 도입
- **수용 기준(AC)**
  - [ ] 간편 모드 기존 UX/결과 유지
  - [ ] 상세 옵션 반영 시 결과 차이가 설명 가능
- **테스트**
  - [ ] 경계값 테스트(옵션 on/off)

### FEAT-007: 세금/부동산 규정 옵션 확장

- **범위(MVP)**
  - 관계/주택 수/지역 등 핵심 옵션을 선택식으로 확장
- **수용 기준(AC)**
  - [ ] 옵션 누락/알 수 없는 값 입력 시 안전 실패 처리
  - [ ] 기준일/버전 정보가 항상 표시
